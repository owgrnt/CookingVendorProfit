# Cooking Vendor Profit

Аддон для WoW Forever 1.60.1 (Interface 16001). Папка `CookingVendorProfit` уже установлена в `_forever_/Interface/AddOns`.

## Как пользоваться

1. После первой установки полностью выйдите из WoW Forever и запустите его заново. На экране выбора персонажа откройте AddOns и проверьте, что включены Cooking Vendor Profit и Auctionator. В настройках Auctionator включите показ стоимости изготовления и прибыли в окне профессии.
2. Откройте Cooking и выберите блюдо. Под `Profit` появится `Торговцу +40%` (в английском клиенте — `To Vendor +40%`). Наведите курсор на строку, чтобы увидеть источники цен.
3. Для обновления цен откройте аукцион и окно Cooking, затем нажмите штатную кнопку **Search** Auctionator. Строка пересчитается, когда Auctionator обновит сохранённые цены. Наведите курсор, чтобы увидеть источник и доступный возраст цен.

4. Панель **Top 10** открывается рядом с Cooking. Чтобы передвинуть её, потяните за заголовок левой кнопкой мыши. Положение сохраняется между сеансами. На аукционе нажмите **Scan All**, чтобы поискать предметы для всех изученных рецептов через Auctionator. Общие ингредиенты ищутся один раз. После завершения панель покажет до десяти блюд с положительной прибылью за одно приготовление. Для переменного выхода рейтинг использует нижнюю границу диапазона. Рецепты с недостающими свежими аукционными ценами исключаются, если для ингредиентов нет известной закупочной цены торговца. После успешного полного скана с прибыльными блюдами становится доступна кнопка **Scan Top 10**. Она заново проверяет только блюда из последней полной десятки и их ингредиенты. Чтобы обновить сам состав десятки, повторите **Scan All**.

Расчёт за одно приготовление — `цена продажи торговцу × (обычный выход + 0,4) − себестоимость`. Для переменного выхода показывается диапазон, а при неизвестной цене хотя бы одного ингредиента числовая прибыль скрывается. Расчёт использует заданные 40% без проверки активного ранга наследия. Аддон определяет еду по игровому типу предмета и заклинанию использования, а для лагерных объектов учитывает идентификаторы из категории Camping.

## Что проверено

- Синтаксис Lua 5.1 и оба языка на эмуляции API.
- При себестоимости 380 меди и цене продажи 312 меди получены +56,8, +368,8 и +680,8 меди для обычного выхода 1, 2 и 3 соответственно. Проверены диапазон, неизвестная цена, загрузка данных, нулевая цена продажи и приоритет закупочной цены торговца.
- Проверены значки меди, серебра и золота, десятые доли меди, цвета, совпадение шрифта с Auctionator и пересчёт после записи новых цен в его базу на эмуляции.

В версии 1.1.0 отображение строки проверено в WoW Forever после `/reload`. Для Hot Wolf Ribs игра показала +65,8 меди при себестоимости 371 медь и цене продажи 312 меди. Версия 1.2.0 использует штатную кнопку Search и игровые значки монет. В версии 1.4.0 общий поиск, ограничение рейтинга десятью рецептами, повторный поиск по десятке и отмена проверены на эмуляции. Эти проверки в живом клиенте пока не проводились.

Для ингредиентов действует заданный приоритет закупочной цены торговца. Установленный Auctionator в новом окне профессий выбирает аукционную цену, если закупочная цена более чем в пять раз выше. В этом случае суммы могут отличаться.
